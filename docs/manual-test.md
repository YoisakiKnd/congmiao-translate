# 手动测试清单

这些项目依赖真实的键鼠或桌面门户，GitHub Actions 里做不了。发版前在对应系统上各走一遍。

## 拖拽截图

1. 打开主窗口，确认已授予屏幕录制（macOS）或对应的截图权限。
2. 用截图快捷键拉出一个包含中英文的区域。
3. 浮窗应显示识别出的文字，并带有「翻译」按钮。
4. 按 Esc 应关掉浮窗，不把主窗口顶到前台。

## 划词替换

1. 在文本框里选中一段英文，触发划词翻译。
2. 确认读到的是选中文字，而不是剪贴板里的旧内容。
3. 选择替换后，原文位置应变成译文。
4. Linux 的 X11 走 `xclip` 的 PRIMARY 选区；Wayland 先复制再翻译。找不到命令时，提示里应包含 `sudo apt install` 和对应包名。

## Wayland 门户截图

1. 在 Wayland 会话里触发截图。
2. 系统应弹出 xdg-desktop-portal 的区域选择框，而不是静默失败。
3. 设置页快捷键一栏应写明：Wayland 下全局快捷键可能无效，可改用托盘菜单，或把系统快捷键指向 `congmiao://translate`。
